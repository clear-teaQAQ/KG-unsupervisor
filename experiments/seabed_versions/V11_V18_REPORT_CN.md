# GEDRanker v11-v18 实验汇报总结

## 一、结论先行

v11-v18 的工作不是不断修改图编辑距离定义，而是在尽量保持 SEABED 第 3 列真值、单位编辑代价和成对偏好监督不变的前提下，逐步解决原始 GEDRanker 在知识图谱场景中的三个问题：

1. 原始模型的图编码器只看节点和拓扑，不看关系类型，但 SEABED 的图编辑距离会计算关系标签错误；
2. SWDF 的真值由无向简单图的“同端点最后一条关系覆盖”口径生成，而早期模型和候选代价仍使用原始多关系边，造成输入、训练代价和最终评测口径不一致；
3. 原始判别器只对候选匹配做整体打分，没有显式分析该匹配保留了哪些关系边、破坏了哪些边。

实验结果表明：

- v11 的关系感知编码是第一个稳定有效的模型改动。相对同口径校正基线，LUBM 的平均绝对误差从 0.110 降到 0.092，SWDF 从 0.341 降到 0.263。
- v12 的显式知识图谱语义评论器没有成功，LUBM 和 SWDF 均明显退化，说明复杂语义辅助损失不能直接叠加到现有训练目标上。
- v14 的“匹配条件边推理”在 LUBM 的同种子配对实验中有效，平均绝对误差从 0.114 降到 0.060，但当时实现速度较慢且只验证了一个数据集、一个种子。
- v15-v16 找到了 SWDF 最关键的问题：图视图不统一。v15 仅统一模型输入后，SWDF 平均绝对误差从 0.263 降到 0.242；v16 将模型、训练候选代价、偏好标签、推理选优和最终评测全部统一到官方简单图视图后，进一步降到 0.070，精确命中率达到 0.934。
- v17 用跨图注意力和 Gumbel-Sinkhorn（加入 Gumbel 随机扰动的双随机归一化匹配）完全替换扩散生成器，结果明显退化，说明原始离散扩散生成机制目前仍然更适合本任务。
- v18 将 v14 的边推理和 v16 的统一图口径结合。LUBM 达到当前最好结果：平均绝对误差 0.050、精确命中率 0.952；SWDF 为 0.081、0.923，略差于 v16，但仍显著优于原始代码和 v11。

因此，当前最稳妥的总判断是：**关系感知编码、官方图口径统一、匹配条件边推理是有效方向；显式语义评论器和直接 Sinkhorn 匹配没有成功。v18 在 LUBM 最优，v16 在 SWDF 最优，暂时还不能说 v18 在所有数据集上全面优于 v16。**

## 二、原始 GEDRanker 与我们的共同实验底座

### 2.1 原始 GEDRanker 做什么

原始 GEDRanker 是一个无监督的匹配式图编辑距离求解器，主体可以概括为：

```text
节点特征与图拓扑
  -> GIN（图同构网络）编码
  -> 离散扩散生成节点匹配
  -> 根据候选匹配计算图编辑距离
  -> BPR（贝叶斯个性化排序，即成对偏好排序）判别器学习候选优劣
  -> 用当前更低代价的匹配更新训练伪标签
  -> 推理时采样 100 个候选并选择代价最低者
```

原论文代码主要面向 AIDS、Linux、IMDB 等普通图数据。它的核心编码器没有利用知识图谱中的关系向量，也没有专门处理同一对端点上的多条关系边。

### 2.2 我们在 v11 之前已经完成的必要适配

v11-v18 继承了此前对原代码的以下适配，这些不是 v11 单独新增的贡献：

- 接入 LUBM、SWDF、YAGO、WIKIDATA 四个 SEABED 知识图谱数据集；
- 固定使用 SEABED 第 3 列图编辑距离真值；
- 使用节点原始向量，关系插入、删除、替换均采用单位代价；
- 将图按无向图处理，并采用 200 轮训练、测试时每对图采样 100 个候选的统一协议；
- 修复 YAGO 和 WIKIDATA 派生图中节点向量顺序与拓扑编号不一致的问题；
- 保持“候选图编辑距离更低才更新结构伪标签”的严格训练主目标。

这一区分很重要：YAGO、WIKIDATA 从原始结果到后期结果的大幅提升，主要包含节点顺序修复的贡献，不能全部归因于 v11-v18 的新模型。

### 2.3 v11-v18 始终保持不变的任务定义

除 v16 开始统一可执行图视图外，v11-v18 没有增加余弦语义编辑代价，也没有修改真值列：

```text
节点输入：原始节点向量
真值：SEABED 第 3 列
编辑代价：单位代价
训练偏好：候选单位图编辑距离的严格大小关系
主要指标：MAE（平均绝对误差）和 ACC（精确命中率）
```

其中，MAE 越低越好；ACC 表示预测图编辑距离与真值完全相等的图对比例，越高越好；FEA（可行率）表示预测值不低于真值的比例。FEA 小于 1 通常意味着当前候选代价口径与真值口径仍可能不一致。

## 三、逐版本说明

### v11：关系感知的图编辑距离训练

**改了什么：** 将生成器和判别器中的 GIN（图同构网络）换成 GINE（带边属性的图同构网络），把 100 维关系向量送入消息传递。正向边和反向边使用同一关系向量，自环使用零向量，方向仍按无向评测处理。扩散过程、BPR 训练、伪标签更新、单位代价和测试选优均不变。

**为什么改：** 原模型虽然最终用关系标签计算图编辑距离，但神经网络本身看不到关系。LUBM 有 97.56%、SWDF 有 99.49% 的测试对会受到关系标签代价影响，模型输入与目标明显不对齐。

**效果：** 独立固定种子评测中，四个数据集均优于同口径基线。LUBM 的 MAE 从 0.110 降至 0.092，ACC 从 0.901 升至 0.916；SWDF 的 MAE 从 0.341 降至 0.263，ACC 从 0.701 升至 0.756。

**结论：** v11 是可靠的正向结果。但 v11 的恒定关系和打乱关系正式对照没有完成，所以目前能确认“带边属性的编码器有效”，尚不能把全部增益严格归因于关系身份语义。

### v12：知识图谱语义偏好评论器

**改了什么：** 在 v11 关系编码之外，为每个候选节点对构造 5 类特征：实体向量相似度、出关系相似度、入关系相似度、度相似度、精确实体锚点。新增语义评论器、教师保持损失、自适应探索和稀疏候选筛选，并完成原始关系、恒定关系、打乱关系和关闭评论器四组 200 轮对照。

**效果：** 完整模式在 LUBM 上为 MAE 0.283、ACC 0.777，在 SWDF 上为 0.546、0.594，均远差于 v11 的 0.092/0.916 和 0.263/0.756。SWDF 关闭语义评论器后反而改善到 0.503/0.615；恒定关系也没有比原始关系更差。

**结论：** 该方案失败。附加语义目标、保持目标和探索目标改变了原有优化平衡，而且消融结果不支持语义评论器有效。后续版本回到“严格保留原图编辑距离任务、一次只加一个小模块”的路线。

### v13：零门控的精确锚点残差

**改了什么：** 在 v11 生成器的节点匹配分数上，只对原始节点向量完全相同的候选增加一个可学习标量偏置。门控初值为 0，因此第一次前向计算与 v11 完全相同。

**效果：** 只完成了 LUBM 基线模式的 200 轮训练和门控模式的冒烟测试。独立评测中，新训练的基线为 0.100/0.906，而直接加载 v11 检查点为 0.092/0.916；门控模式没有正式 200 轮结果。

**结论：** v13 不能宣称有效。它验证了“零门控、先保持基线”的实验设计方法，但没有完成新模块的正式效果验证。

### v14：匹配条件边推理

**改了什么：** v11 只在生成候选之前编码关系；v14 让判别器进一步看到“某个具体候选匹配会怎样改变边”。对两侧真实边分别构造三类可微事件：关系边被精确保留、端点关系存在但关系类型错误、边被破坏或产生多余边。判别器得分为 v11 得分加零初值门控的边推理残差。

**效果：** LUBM 同种子独立配对评测中，基线为 MAE 0.114、ACC 0.897，加入边推理后为 0.060、0.942；MAE 降低约 47.4%，ACC 提高 4.5 个百分点。相对 v11 固定种子结果也更好。

**结论：** 边推理方向有效，但证据仅来自 LUBM、种子 0。原实现逐图对建立邻接并循环处理，速度较慢，没有继续完成 SWDF 和多种子验证，后续由 v18 做向量化重构。

### v15：按基准口径投影关系输入

**改了什么：** 发现 SWDF 第 3 列真值通过无向简单图生成，同一端点对只保留原始数据中最后出现的关系；v11 却把所有并行关系边都送入 GINE。v15 仅将模型输入投影成“无向、同端点最后写入”的简单图，候选代价计算仍保留 v11 原始边视图，从而隔离输入表示的影响。

**数据诊断：** SWDF 的 1,000 张图中有 678 张受影响，8,124 条原始边投影后剩 6,701 条，删除 1,423 条并行边，占 17.516%；92.31% 的测试图对至少包含一张受投影影响的图。LUBM 没有并行端点边，因此投影前后完全一致，是有效的无变化对照。

**效果：** SWDF 配对实验中，原始输入为 MAE 0.263、ACC 0.757，投影输入为 0.242、0.773，MAE 降低约 8.0%，ACC 提高 1.6 个百分点。

**进一步审计：** 对同一批 100 个候选仅改用官方简单图代价重新排序，可达到 MAE 0.0942、ACC 0.9107；原选择方式只有 0.2385、0.7747。这说明模型已经生成了很多好候选，但旧代价口径经常选错候选。

**结论：** v15 证明 SWDF 的主要问题不只是模型能力，还有输入视图和候选代价视图不一致。这直接推动了 v16。

### v16：全流程统一官方图视图

**改了什么：** v15 只投影模型输入；v16 将同一张“无向、最后写入”的简单图用于模型编码、训练展开图编辑距离、BPR 偏好标签、最佳伪标签更新、100 候选选优和最终评测。真值列和单位编辑规则不变，但所有代码消费者终于使用同一图视图。

**效果：** SWDF 达到 MAE 0.070、ACC 0.934、FEA 1.000，相对 v11 的 0.263/0.756，MAE 降低约 73.4%，ACC 提高 17.8 个百分点。另一次同配置运行为 0.073/0.930，说明结论稳定但仍有随机波动。LUBM 没有边投影变化，结果为 0.113/0.896，反而略差于 v11。

**结论：** v16 是当前 SWDF 最好且最关键的结果。它表明旧流程的最大瓶颈是“模型、训练代价、推理选优、真值”没有采用一致的图语义。需要强调，这个巨大提升既包括训练改进，也包括候选选优和评测口径修正，不能全部描述成神经网络结构提升。

### v17：跨图 Sinkhorn 直接匹配

**改了什么：** 完全替换 v11 的离散扩散生成器。先用 GINE 编码两张图，再做跨图查询—键注意力和节点对打分，最后通过带虚拟源节点的矩形 Gumbel-Sinkhorn 直接产生一一匹配。判别器和 v16 官方图代价保持不变。

**效果：** 200 轮后，LUBM 为 MAE 0.525、ACC 0.633，SWDF 为 0.450、0.664，远差于 v16。虽然比 20 轮试验有所收敛，但仍未达到可接受水平。

**结论：** v17 失败。当前的直接软匹配松弛与原有伪标签/BPR 训练机制不够匹配，去掉扩散时间步和逐步去噪后，候选质量明显下降。原 GEDRanker 的离散扩散生成器应继续保留。

### v18：官方图上的匹配条件边推理

**改了什么：** 组合 v16 的统一官方图、v11 的关系感知扩散生成器和 v14 的匹配条件边推理。与 v14 相比，v18 预先缓存边对应索引，并用批量收集与池化替代逐图对循环；训练后半程探索权重为 0 时跳过无效的判别器前向计算。

**效果：** 四数据集 200 轮训练已完成，尽管目录中的旧版结果说明尚未更新。LUBM 为 MAE 0.050、ACC 0.952，是当前最佳；SWDF 为 0.081、0.923，略差于 v16 的 0.070/0.934；YAGO 为 0.001/1.000；WIKIDATA 为 0.039/0.964。

**结论：** v18 证明统一图口径上的边推理可以显著改善 LUBM，但没有在 SWDF 上超过 v16。目前只有种子 0 的完整新模块训练，没有完成 200 轮同路径关闭模块基线以及种子 1、2，因此应表述为“当前最佳候选方案”，不能表述为“已完成多种子验证的最终模型”。

## 五、需要主动说明的实验边界

1. **YAGO 和 WIKIDATA 不能作为主要模型效果证据。** 已有审计证明，这两个数据集的第 3 列真值在所有测试对上都等于图规模下界，图编辑距离数值本身存在捷径。更有意义的是节点对应质量，而不是接近 100% 的 GED 精确命中率。
2. **WIKIDATA 的 v16/v18 简单图结果仍有口径问题。** v18 的 FEA 为 0.964，并记录了大量候选代价低于给定真值的情况。因此 0.039/0.964 不能作为完全可行的官方最终结果；WIKIDATA 更适合继续使用多关系可执行路径审计。
3. **v11 的因果消融不完整。** v11 自身没有完成恒定关系和打乱关系的 200 轮对照；v12 虽有这些对照，但同时改变了训练损失，不能替代 v11 的单因素消融。
4. **v14 的正结果范围有限。** 只有 LUBM、种子 0 的完整配对结果，尚缺 SWDF 和多种子统计。
5. **v18 的正式结果比说明文档新。** 四数据集 200 轮结果文件已经存在，但 `RESULTS.md` 仍写“正式训练待完成”。汇报应以运行清单和结果 JSON 为准，并说明结果文档尚待同步。
6. **v18 尚未满足预先设定的最终验收条件。** 缺少同路径 200 轮关闭边模块的配对基线、种子 1 和 2，以及独立重载检查点后的固定种子评测。
7. **不同版本的结果不应全部混成同一种贡献。** v11、v14、v17 主要是模型结构实验；v15 是输入视图实验；v16 同时修正训练和评测全流程口径；v18 才是口径统一后的模型增强。

## 六、建议向老师汇报的主线

可以把整个过程概括为“先让模型看见正确的信息，再让训练和评测使用同一张图，最后让判别器理解一个具体匹配对边的影响”：

```text
原始 GEDRanker：只看节点和拓扑
  -> v11：加入关系属性，LUBM/SWDF 都提升
  -> v12-v13：尝试显式语义辅助，发现复杂损失不稳定
  -> v14：改为直接分析候选匹配造成的边保留/破坏，LUBM 有效
  -> v15：发现 SWDF 的模型输入与官方真值图口径不一致
  -> v16：统一整个训练和评测图视图，SWDF 获得最大提升
  -> v17：尝试替换扩散生成器，失败，说明原扩散机制仍必要
  -> v18：把统一图视图与边推理结合，取得 LUBM 最优、SWDF 次优结果
```

最值得强调的研究认识不是“版本越高一定越好”，而是：

- **关系标签必须进入模型，因为它本来就在图编辑距离目标中；**
- **训练输入、候选代价、偏好监督、推理选优和最终评测必须共享同一图语义；**
- **对知识图谱匹配，显式分析匹配后的边事件比堆叠通用语义相似度损失更有效；**
- **原 GEDRanker 的离散扩散候选生成仍有价值，不能被简单的直接软匹配替代。**

## 七、可直接使用的口头汇报稿

老师，我们从 v11 到 v18 主要是在解决原始 GEDRanker 与知识图谱图编辑距离任务不匹配的问题。原始 GEDRanker 用图同构网络和离散扩散来生成节点匹配，再通过成对偏好判别器学习哪些匹配更好，但它的编码器只看节点和拓扑，不看关系类型。SEABED 第 3 列真值却会计算关系标签替换，所以模型输入和目标之间有缺口。

v11 首先把普通图同构网络换成带边属性的图同构网络，让生成器和判别器都能使用关系向量。在不改变真值、单位代价、扩散过程和评测方式的情况下，LUBM 的平均绝对误差从 0.110 降到 0.092，SWDF 从 0.341 降到 0.263，说明关系感知是有效的。

之后我们尝试了两类语义增强。v12 加入实体相似度、入出关系相似度、精确锚点等语义评论器，但两个主数据集都明显退化；v13 的精确锚点门控只完成了基线和冒烟验证，没有形成正式结论。这说明直接叠加复杂语义损失会破坏原有训练平衡。

所以 v14 改成更贴近图编辑距离本身的方案：让判别器针对一个具体候选匹配，分析关系边是被精确保留、关系类型匹配错误，还是被破坏。LUBM 的同种子配对结果从 0.114/0.897 提升到 0.060/0.942，证明这种边级推理有效，但当时实现较慢，也没有完成多数据集多种子验证。

在 SWDF 上，我们进一步发现更关键的问题。官方真值使用无向简单图，同一端点对只保留最后一条关系，但模型一直读入全部并行边。v15 只把模型输入投影到官方口径，MAE 从 0.263 降到 0.242。候选审计又发现，同样的 100 个候选如果按官方口径重新选优，可以达到 0.094，说明很多错误不是没生成好候选，而是旧代价选错了候选。

因此 v16 把模型输入、训练候选代价、偏好标签、伪标签更新、推理选优和最终评测全部统一到同一张官方简单图。SWDF 最终达到 MAE 0.070、ACC 0.934，是当前最好结果。这个提升需要正确表述为全流程语义对齐的贡献，而不只是网络结构贡献。

v17 尝试用跨图注意力和 Sinkhorn 直接匹配替换离散扩散生成器，但 LUBM 和 SWDF 都明显退化，所以我们保留原扩散生成机制。v18 最后把 v16 的统一图口径和 v14 的边推理结合，并把边推理做成缓存和批量计算。LUBM 达到当前最好结果 0.050/0.952；SWDF 是 0.081/0.923，仍然很好，但略低于 v16。

所以目前的结论是：v18 是 LUBM 最优候选，v16 是 SWDF 最优方案。有效的三个因素是关系感知编码、全流程官方图口径统一、匹配条件边推理；失败的方向是复杂语义评论器和直接 Sinkhorn 匹配。下一步需要补 v11 的关系消融、v18 的同路径关闭模块基线和三个随机种子，同时单独修正 WIKIDATA 的多关系评测口径。
